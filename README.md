# 🎧 THE SOUND PROJECT

프리미엄 오디오 브랜드 컨셉을 기반으로  
헤드셋, 스피커, 사운드바 제품을 소개하는 반응형 웹사이트입니다.

---

## 📌 프로젝트 개요
- 프로젝트명: THE SOUND PROJECT
- 유형: 브랜드 컨셉 웹사이트
- 목표: 프리미엄 오디오 브랜드 무드와 제품 소개를 결합한 웹 퍼블리싱
- 제작 방식: HTML / CSS / JavaScript / jQuery
